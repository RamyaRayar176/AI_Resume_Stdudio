# AI Powered College Placement Prediction System

## Project Description

This project predicts student placement probability using Machine Learning and provides career guidance.

## Features

- Student Registration
- Student Login
- Placement Prediction
- Skill Gap Analysis
- Career Recommendation
- Dashboard Analytics

## Technologies Used

### Frontend
- React JS
- HTML
- CSS
- JavaScript

### Backend
- Flask
- Python

### Database
- MySQL

### Machine Learning
- Scikit-learn
- Pandas
- NumPy

## Installation

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
pip install -r requirements.txt
python app.py
```
